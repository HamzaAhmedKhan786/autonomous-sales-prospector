# Production owner checklist

- [ ] Select cloud, region, domain, branding and legal entity
- [ ] Provision an encrypted persistent volume and verified SQLite backup/restore
- [ ] Contract a licensed profile provider and approve the prospecting lawful basis
- [ ] Create production Groq/Tavily keys with quotas and spend alerts
- [ ] Configure CRM URL, organization ID and matching shared secret
- [ ] Configure email domain, SPF, DKIM, DMARC, unsubscribe, bounce/reply webhooks
- [ ] Set sender/company/offer context and have sales/legal approve templates
- [ ] Set retention periods, privacy notice, processor agreements and request owner
- [ ] Remove demo users/test prospects and rotate all development credentials
- [ ] Complete tenant-isolation, authorization, dependency and penetration testing
- [ ] Connect monitoring/error tracking and name an on-call owner
- [ ] Test staging research, CRM sync, opt-out, deletion, backup restore and rollback
